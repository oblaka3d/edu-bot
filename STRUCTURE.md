# 📁 Структура проекта EduBot

```
edu-bot/
├── README.md                 # Общее описание
├── STRUCTURE.md             # Этот файл — описание архитектуры
├── requirements.txt         # Python зависимости
├── run.sh                   # Скрипт запуска
├── .env.example             # Пример конфигурации
│
├── roadmaps/                # 📚 Markdown-файлы с курсами
│   ├── go-backend.md        # Курс Go Backend
│   ├── python-backend.md    # Курс Python Backend
│   └── js-frontend.md       # Курс JavaScript Frontend
│
├── data/                    # 🗄️ Данные (SQLite)
│   └── users.db             # База данных пользователей
│
└── src/                     # 💻 Исходный код
    ├── bot.py               # Главный файл бота
    ├── database.py          # Работа с SQLite
    ├── roadmaps.py          # Парсер Markdown роудмапов
    └── scheduler.py         # Планировщик напоминаний
```

## 🏗️ Архитектура

### 1. База данных (database.py)

**Таблицы:**

- **users** — информация о пользователях и текущий прогресс
  - user_id, username, selected_track, current_stage, current_topic
  
- **progress** — история пройденных тем
  - user_id, track, stage, topic, completed_at
  
- **reminders** — настройки напоминаний
  - user_id, track, schedule_type, days, time, is_active

### 2. Парсер роудмапов (roadmaps.py)

Парсит Markdown-файлы в структурированные данные:
- Разбивает на этапы (`## Этап N: Название`)
- Извлекает темы (`### Тема N.M: Название`)
- Парсит секции: **Изучим**, **Практика**, **Ресурсы**, **Видео**
- Извлекает Markdown-ссылки `[текст](url)`

### 3. Планировщик (scheduler.py)

- Работает в отдельном потоке
- Проверяет каждую минуту, есть ли напоминания
- Отправляет сообщения пользователям с текущей темой
- Поддерживает: будни, выходные, произвольные дни

### 4. Бот (bot.py)

**Основные команды:**
- `/start` — приветствие и регистрация
- Inline-кнопки для навигации

**Потоки:**
1. **Выбор направления** → сохранение в БД
2. **Обучение** → показ темы → отметка пройденной → следующая
3. **Прогресс** → статистика и история
4. **Напоминания** → выбор дней/времени → сохранение

## 🚀 Как добавить новый курс

1. Создать файл `roadmaps/new-course.md` по формату выше
2. Добавить отображаемое имя в `get_track_display_name()` в `roadmaps.py`
3. Перезапустить бота

Готово! Курс автоматически появится в списке выбора.

## ⚙️ Настройка напоминаний

- **Будни** — Пн, Вт, Ср, Чт, Пт
- **Выходные** — Сб, Вс
- **Свои дни** — выбор любых дней недели
- **Время** — фиксированные интервалы (09:00, 10:00, ...)

При наступлении времени бот отправляет сообщение с текущей темой.

## 🎉 Завершение курса

Когда пользователь проходит последнюю тему последнего этапа:
- Показывается поздравительное сообщение
- Предлагается начать новый курс
- Прогресс сохраняется в БД

## 🔧 Расширение функциональности

### Добавить новое поле в БД
1. Добавить в `init_db()` CREATE TABLE
2. Добавить функции чтения/записи в `database.py`
3. Использовать в `bot.py`

### Добавить новую команду
1. Создать `async def command_name(update, context)`
2. Добавить `application.add_handler(CommandHandler("command", command_name))`
3. Добавить кнопку в нужное меню

### Изменить формат вывода темы
Модифицировать `format_topic_for_display()` в `roadmaps.py`
